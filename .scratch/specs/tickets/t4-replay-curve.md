## Parent

#29（spec: 时间线复盘系统——规则转折点 + AI 叙述 + 回填补拉时间线）

## What to build

车队成员在对局详情页打开复盘区块：看到整局经济差曲线（正=我方领先），曲线上有可交互的击杀事件标记（时刻与涉及成员），关键转折点（经济差极值、一血、团灭、大龙、经济反超时刻）高亮标注，一眼看出胜负手。查看没有时间线数据的对局时，复盘区块显示降级提示与 stats 层简要信息，而非空白曲线或报错。

转折点由后端规则引擎从 frames **确定性提取**（纯函数：frames 进、转折点列表出），每个转折点携带真实上下文（游戏内时刻、双方经济差、涉及成员与事件明细）。桌面端已采集的局立即被覆盖（本票不依赖回填补拉）。

## Acceptance criteria

- [ ] 转折点规则引擎为纯函数服务，判定结果可从 frames 复算验证；候选类型至少含经济差极值、一血、团灭、大龙、经济反超时刻；规则参数可配置
- [ ] 对局详情新增复盘数据端点：经济差序列 + 事件标记 + 转折点列表（带上下文）
- [ ] Web 详情页复盘区块：Chart.js 经济差曲线（复用既有差距曲线组件先例）+ 事件标记可悬停/点击 + 转折点高亮
- [ ] 无时间线对局降级：不渲染曲线，显示降级提示与 stats 简要信息
- [ ] AI 不参与本票任何环节
- [ ] controller 只做参数校验与返回封装，引擎与聚合逻辑在 service 层
- [ ] TDD：转折点引擎黄金样本单测（含已知事件的 frames → 断言提取结果），先例为 OP Score 评分引擎纯计算测试；降级行为测试覆盖
- [ ] 复盘数据端点/降级判定有日志

## Blocked by
